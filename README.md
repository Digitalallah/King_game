# Кинг — Telegram-адаптация

Нативная браузерная версия карточной игры «Кинг» Вадима Башурова (1993). Игра работает напрямую на JavaScript и Canvas, без DOS-эмулятора.

## Что работает

- все 12 оригинальных персонажей с именами, извлечёнными из `KING.EXE`;
- все 32 карты и оригинальный пиксельный шрифт, декодированные без перерисовки из ресурсов игры;
- выбор трёх партнёров одним кликом или тапом с оригинальной характеристикой выбранного героя;
- любой смешанный состав: от одного до трёх живых оппонентов, остальные места занимают выбранные персонажи ИИ;
- Telegram-приглашение по deep link, комната со статусами и старт только после подключения всех выбранных людей;
- имя игрока задаётся перед входом, а аватар берётся из подписанных Telegram-данных;
- выбор карты первым тапом и ход вторым тапом по приподнятой карте;
- обязательный ход в масть, ограничения на выход с червей и сброс Кинга;
- 14 последовательных контрактов: семь штрафных и семь положительных;
- общий счёт по всем контрактам, финальная таблица с местами, победитель или ничья;
- автоматическое сохранение незаконченной партии и продолжение после повторного запуска;
- явная надпись «Ваш ход»;
- четыре карты остаются на столе до следующего тапа, затем одним кадром складываются у победителя, ненадолго задерживаются и исчезают;
- тихие сигналы PC Speaker в стиле оригинальной версии с кнопкой включения и выключения звука;
- автоматическое вписывание поля 640×350 в экран, включая горизонтальную ориентацию телефона;
- запрос полноэкранного режима при повороте телефона горизонтально;
- окна «Правила» и «Об игре»;
- запуск в обычном браузере и Telegram Mini App;
- автоматическое возвращение в сетевую комнату после обрыва или повторного запуска.

В сетевом режиме колода, руки, очерёдность, ходы ИИ и счёт ведёт один авторитетный Durable Object. Клиент получает только свою руку и счётчики чужих карт.

## Оригинальные ресурсы

Карты, портреты, рубашка и элементы интерфейса читаются из `assets/native/king.lib.bin`. Русский растровый шрифт читается из `assets/native/king.fnt.bin`. Оба файла извлечены из предоставленного архива и проверяются тестами по SHA-256.

Нативный декодер сохраняет исходную 16-цветную EGA-палитру и внутреннее разрешение 640×350. Мышь DOS и нарисованный курсор-рука не используются: координаты тапа сразу попадают в элементы игрового состояния.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm start
```

Откройте http://localhost:8080. Этот лёгкий сервер предназначен для одиночной игры. Для локальной проверки комнат используйте `wrangler dev` и не коммитьте `.dev.vars`.

## Проверка

```bash
npm test
npm run check
```

Тесты проверяют декодирование оригинальных ресурсов, правила и все 14 контрактов, мобильные тапы, смешанную сетевую партию до финала, комнаты, Telegram-подпись и защиту приватных рук.

## Cloudflare / Telegram

```bash
npx wrangler@4.122.0 secret put BOT_TOKEN
npx wrangler@4.122.0 deploy
```

Полученный HTTPS-адрес указывается в BotFather как URL Mini App. Публичные `BOT_USERNAME` и `APP_SHORT_NAME` заданы в `wrangler.jsonc`; если бот или short name изменились, обновите их перед деплоем. `BOT_TOKEN` хранится только как Cloudflare secret.

Приглашение имеет вид `https://t.me/<bot>/<app>?startapp=room_<id>`. Telegram `initData` передаётся серверу только в POST-теле, проверяется по HMAC и не попадает в URL или публичное состояние комнаты.

## Структура

- `src/native-assets.js` — декодер графики, шрифта и EGA-рендерер;
- `src/game-engine.js` — колода, правила контрактов, подсчёт и ИИ;
- `src/network-client.js` — Telegram deep link, вход, WebSocket и восстановление связи;
- `src/native-game.js` — состояния игры, canvas-интерфейс и управление тапами;
- `assets/native/` — оригинальные графические данные;
- `worker/network-game.js` — авторитетная сетевая партия;
- `worker/game-room.js` — Durable Object комнаты и сессии;
- `worker/index.js` — проверка Telegram, API, защитные заголовки и раздача файлов.
