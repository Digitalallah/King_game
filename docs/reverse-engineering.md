# Первичный разбор оригинального «Кинга»

## Подтверждено запуском оригинала

- Игра показывает себя как «Короткий вариант игры», версия 1.7 от 22 августа 1993 года.
- Автор — Вадим Башуров; программа написана на Turbo Pascal с собственным графическим пакетом.
- Рабочее разрешение — 640×350.
- `KING.EXE` запускает режим «все виды партий по очереди».
- `KING2.EXE` запускает режим, где игроки по очереди выбирают вид игры.
- После служебной заставки игрок выбирает трёх партнёров из 12 персонажей.
- Управление выбором персонажей и карт работает мышью; в Telegram оно преобразовано в касания.

## Правила из `KING.HLP`

Колода состоит из 32 карт. Игрок обязан ходить в масть; при отсутствии масти можно сбросить любую карту. Взятку забирает старшая карта масти первого хода, её победитель начинает следующий ход.

Последовательность `KING.EXE`:

1. не брать взятки — по −20;
2. не брать червей — по −20;
3. не брать мальчиков, то есть королей и валетов;
4. не брать девочек, то есть дам;
5. не брать две последние взятки;
6. не брать Кинга — короля червей;
7. Ералаш — одновременно действуют все штрафы;
8. затем те же контракты играются на положительные очки.

В контрактах «Черви», «Кинг» и «Ералаш» нельзя начинать взятку с червей, пока у игрока есть другая масть.

## Что было удалено из прежнего прототипа

Предыдущий интерфейс использовал HTML-карты, эмодзи-портреты, самостоятельно написанных ботов и серверный сетевой матч. Это не совпадало с оригиналом визуально и не могло гарантировать исходное поведение ИИ. Фальшивые галереи ресурсов и сетевой код удалены из активной ветки; при необходимости они доступны в истории Git.
