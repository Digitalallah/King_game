# Исходные файлы игры

Активный прототип использует предоставленный архив `kingrus.zip` со следующей контрольной суммой SHA-256:

```text
64d0d5dae0a536626e944af58314b48a13682a49221d01a518fb01c86e53f153
```

Внутри находятся исполняемые файлы двух вариантов игры, `KING.LIB`, `KING.FNT`, справка и служебные файлы. Активная браузерная версия не запускает DOS-код: из архива взяты только графическая библиотека и растровый шрифт.

Для нативного клиента они хранятся как `assets/native/king.lib.bin` и `assets/native/king.fnt.bin`. Расширение `.bin` отделяет необходимые данные от исполняемого кода. Декодер `src/native-assets.js` восстанавливает 49 непустых спрайтов из 72 позиций библиотеки и три плоскости шрифта; тесты фиксируют SHA-256 обоих файлов.

Для локального исследования распакованные файлы можно положить в игнорируемый каталог `assets/original/`:

```bash
python3 scripts/extract_original_assets.py /path/to/kingrus
```
